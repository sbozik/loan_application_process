# Loan Application Process – System Analysis Case Study

This repository contains a small portfolio case study focused on the analysis of a **Loan Application Process**.

The project was created to demonstrate how I approach an early-phase IT analysis task: defining scope, describing the main workflow, identifying core data entities, mapping system interactions, and outlining basic API design.

It is a **system and process analysis project**, not a working software application.

---

## Project Purpose

The purpose of this case study is to show how a simple business process can be translated into structured analysis outputs that could support further discussion with developers, testers, or business stakeholders.

The analyzed system allows a customer to submit a loan application online. The application is validated, evaluated through a **Credit Scoring Service**, and then approved or rejected.

---

## Scope

### Included in MVP
- loan application submission
- customer data validation
- credit scoring request
- loan decision

### Excluded from MVP
- payment schedule generation
- loan contract management
- customer authentication

---

## Included Analysis Outputs

This case study contains:
- process overview
- use case description
- simplified data entities
- ERD
- sequence diagram for system interaction
- REST API endpoint suggestions
- example validation rules
